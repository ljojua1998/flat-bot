# ბინების ტრეკერი (myhome.ge + ss.ge → Telegram)

ყოველ 4 წუთში ამოწმებს myhome.ge-სა და ss.ge-ზე თბილისის ახალ განცხადებებს
(ბინა / კომერციული ფართი, ყიდვა / ქირა) და Telegram-ში უგზავნის მათ,
ვისი ფილტრიც ემთხვევა (უბნები, ფასი, ფართი).
მოდის ყველა ახალი განცხადება, მესაკუთრისაც და მაკლერისაც.

ერთი და იგივე ქონება, რომელიც რამდენიმე მაკლერმა ან ორივე საიტზე დადო,
ერთხელ მოდის. დანარჩენი ლინკები იმავე შეტყობინებას ემატება („➕ იგივე ბინა“).
დუბლიკატს ცნობს ფოტოს ჰეშით, ss.ge-ს similarityGroup-ით და ფართი + სართული + ფასით.

## გაშვება

1. Telegram-ში გახსენი @BotFather → `/newbot` → დააკოპირე ტოკენი.
2. `.env.example` დააკოპირე `.env`-ად და ჩაწერე ტოკენი.
3. `pip install -r requirements.txt`
4. `start.bat` (ან `python main.py`)

პირველ გაშვებაზე ბოტი ~5 წუთი „ითბობს“: არსებულ განცხადებებს ინახავს და არ აგზავნის,
შემდეგ მხოლოდ ახლებს აგზავნის.

სატესტო გაშვება Telegram-ის გარეშე: `python main.py --once`

## ბრძანებები

მომხმარებელი: `/start` `/setup` `/filter` `/pause` `/resume` `/plans`

ადმინი (`ADMIN_CHAT_IDS`): `/users`, `/stats`, `/setplan <chat_id> <4|6|8|999>`.
პირველ ეტაპზე გადახდა ხელით ხდება: მომხმარებელი იხდის, ადმინი `/setplan`-ით უხსნის ლიმიტს.

ბოტი ჯგუფშიც მუშაობს: დაამატე ჯგუფში და ჯგუფში დაწერე `/setup`.

## ფაილები

- `sources.py` — საიტებიდან წამოღება (Next.js `__NEXT_DATA__`)
- `dedup.py` — დუბლიკატების ამოცნობა
- `tracker.py` — პოლინგი, ფილტრები, შეტყობინებები
- `bot.py` — Telegram დიალოგი
- `districts.py` — რაიონები და უბნები
- `data.sqlite3` — ბაზა, `tracker.log` — ლოგი
